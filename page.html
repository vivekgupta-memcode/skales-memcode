Save a fact you choose. Search or ask about it later. Nothing is copied from your Skales chats or local memory automatically.

Connect once

In Skales, enable the MCP Servers add-on, then open Settings → Extensions → MCP servers. Add a remote HTTP server named memcode with URL https://mcp.memcode.in/mcp. Enable OAuth and complete the browser sign-in. Do not enter an API key in this page.

The server name matters: Skales exposes its tools as mcp_memcode_*. The connection and authorization are managed by Skales.
